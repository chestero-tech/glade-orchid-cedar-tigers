Loops in Arduino

How a microcontroller repeats work — the four loops you will actually use, when to pick each one, and the smallest examples that still make sense.

A loop is a way to say “do this again.” Computers are great at repeating. You should almost never copy-paste the same 5 lines of code 20 times. Write the action once, then wrap it in a loop.

1. The Arduino loop() — the forever loop

Special Arduino function

void loop()

Use it for: the main job of your sketch. After setup() finishes once, Arduino runs loop() over and over until you unplug the board.

This is not a C++ keyword like for. It is a required function in every Arduino sketch. Think of it as the heartbeat of the program.

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(500);
  digitalWrite(LED_BUILTIN, LOW);
  delay(500);
}  // goes back to the top automatically

2. The for loop — “do this N times”

Counting loop

Use it when: you already know how many times to repeat. Blink 5 times. Count 0–9. Walk through pins 2 through 6.

A for loop has three parts in the parentheses, separated by semicolons:

  1. Start — make a counter and give it a first value
  2. Condition — keep going while this is true
  3. Update — change the counter after each pass
// Blink the built-in LED exactly 5 times
void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
  for (int i = 0; i < 5; i++) {
    digitalWrite(LED_BUILTIN, HIGH);
    delay(200);
    digitalWrite(LED_BUILTIN, LOW);
    delay(200);
  }
}

void loop() {
  // nothing — the 5 blinks already happened
}

3. The while loop — “keep going as long as…”

Condition loop

Use it when: you do not know the count. Wait until a button is pressed. Wait until a sensor reading is high enough. Keep polling until something changes.

The test happens before the body. If the condition is already false, the body never runs.

You are responsible for changing something inside the loop so the condition can become false. If you forget, you create an infinite loop.

const int buttonPin = 2;

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
  pinMode(buttonPin, INPUT_PULLUP);
  digitalWrite(LED_BUILTIN, HIGH);  // LED on = waiting

  while (digitalRead(buttonPin) == HIGH) {
    // do nothing until the button is pressed
  }

  digitalWrite(LED_BUILTIN, LOW);   // LED off = go!
}

void loop() { }

4. The do-while loop — “do it at least once”

Run-then-check

Use it when: the body must happen once before you even look at the condition. Read a sensor at least once. Show a menu once, then keep showing it until the user picks a valid choice.

Same idea as while, except the test is at the bottom. Notice the semicolon after while (condition);

int reading = 0;

void setup() {
  Serial.begin(9600);
  do {
    reading = analogRead(A0);
    Serial.println(reading);
    delay(50);
  } while (reading < 100);
}

void loop() { }

Which loop should I pick?

Loop Best for Know the count? Runs at least once?
loop() The whole sketch after setup No — runs forever Yes, until power off
for A fixed number of repeats Yes Only if the start already passes the test
while Wait for an event or sensor No No — test first
do-while Must try once, then maybe repeat No Yes — body first
Watch out for infinite loops. If a while or do-while condition never becomes false, the board sits in that loop and the rest of your program never runs. Classic mistake: forgetting to change the variable (or read the button) inside the loop. loop() is supposed to be infinite. The others usually are not.
Classroom memory trick. for = “I already know how many.”   while = “keep going while this is true.”   do-while = “do it, then ask if we should do it again.”   loop() = “the sketch’s heartbeat.”
Try it (10 minutes).
  1. Use a for loop in setup() to blink the built-in LED 3 long, 3 short (Morse “S” is three shorts — make an “SOS” if you want extra credit).
  2. Add a button on pin 2. Use a while loop so nothing else happens until the button is pressed.
  3. Rewrite the 5-blink for example as a while loop. Same result, different tool. Which version is easier to read?
Arduino language is based on C++. These same loop rules work in most programming languages you will meet later.
